What this is
A face runtime sketch, not Broderick’s files. Opacity/Zoah do not ship a character SDK. The tweet is the taste: sphere + tall capsule, two pills for a face, construction-line cuteness, talk without a jaw.
Talk without lips
A talking class squash-stretches the body at ~6 Hz and pulses the eyes. Drive it with TTS amplitude or a boolean. No visemes.

This file. Later: Rive if a designer rigs the same inputs (isTalking, emotion, audioLevel). FluxGarage RoboEyes / Grobot_Animations for the eye-mood API. Zdog if we want a real 3D equator on the sphere. Do not import Open-LLM-VTuber or a photoreal avatar.
